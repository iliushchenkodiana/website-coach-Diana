# Сайт Діани Ілющенко — фінальна версія

Продакшн-сайт лайф-коуча (ICF). Зібраний із затвердженого прототипу `diana_website_draft.html`.
Дизайн, тексти (UA/EN), тарифи, форма, оплата — фінальні.

**Адреса сайту:** https://iliushchenkodiana.github.io/website-coach-Diana/
(домен не підключений — свідоме рішення; можна додати будь-коли пізніше)

## 📁 Структура

```
├── index.html                  ← головна сторінка
├── style.css                   ← стилі головної
├── script.js                   ← логіка (UA/EN, лічильник, карусель, форма, попап сертифікатів)
├── images/                     ← 7 фото: hero, diana, 5 сертифікатів
├── legal.css                   ← стилі юридичних сторінок
├── privacy_policy.html         ← Політика конфіденційності
├── terms_and_conditions.html   ← Умови та положення
├── cookie_policy.html          ← Політика використання файлів cookie
├── public_offer.html           ← Договір публічної оферти
├── robots.txt / sitemap.xml
└── .nojekyll
```

Юридичні сторінки згенеровані з твоїх `.docx` (Desktop) і оформлені в стилі сайту. Посилання на них уже стоять у футері та в чекбоксі згоди під формою заявки.

## 🚀 Як оновлювати сайт надалі

Файли лежать локально в цій папці й повʼязані з репозиторієм GitHub. Після будь-яких змін — залити їх у репозиторій (через GitHub Desktop одна кнопка «Push», або `git push`). GitHub Pages сам оновить сайт за 1–2 хв.

> У `index.html` активи підключені з версією `?v=1`. Якщо колись зміниш `style.css`/`script.js` і побачиш старе — підніми цифру (`?v=2`), щоб браузери не показували кеш.
