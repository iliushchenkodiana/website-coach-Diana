# Сайт Діани Ілющенко — інструкція

Продакшн-версія сайту, зібрана із затвердженого прототипу `diana_website_draft_17.html`.
Дизайн, тексти (UA/EN), кольори, шрифти, анімації, ціни — **збережені без змін**.

---

## 📁 Структура проєкту

```
├── index.html        ← сторінка (розмітка)
├── style.css         ← усі стилі
├── script.js         ← логіка: перемикач мов, FAQ, параллакс, відгуки
├── images/           ← 4 оптимізовані фото (винесені з base64):
│   ├── diana.jpg           ← фото профілю
│   └── benefit-1..3.jpg    ← фото в картках «Для чого працювати з коучем»
├── source-photos/    ← оригінали фото карток у повній якості (НЕ деплоїться, для архіву)
├── CNAME             ← домен (dianailiushchenko.com)
├── .nojekyll         ← щоб GitHub не «чіпав» файли
├── robots.txt        ← для пошукових систем
└── sitemap.xml       ← мапа сайту
```

Сторінка + фото важать разом ~320 КБ (замість 430 КБ одним файлом), фото завантажуються окремо і «ліниво».

> `source-photos/` — це важкі оригінали Unsplash (по 1–2 МБ), із яких зроблено оптимізовані `benefit-*.jpg`. Тримаю їх окремо, щоб не роздувати сайт. **На GitHub цю папку можна не завантажувати.**

## ✅ Що я зробив (технічна частина)

1. Розбив один файл на `index.html` + `style.css` + `script.js`.
2. Виніс 4 фото з base64 в `images/`, додав lazy-load.
3. **Форма заявки** — власна форма в стилі сайту (Ім'я / Телефон / Telegram). При відправці дані летять **напряму в твою Google-форму** (`forms.gle/mDKdVnSoRuvdP1Wo6`) у фоні, без інтерфейсу Google. Після відправки — блок «Дякую! Заявку отримано».
4. Додав `CNAME`, `.nojekyll`, `robots.txt`, `sitemap.xml`, SEO/Open Graph-теги, favicon.
5. Заготовив блок Google Analytics (закоментований — чекає твій ID).
6. Перевірив адаптив на 375/390/428px, зокрема фото профілю.
7. Зберіг фон через `.bg-fixed` (position:fixed) — як у прототипі.

> **Про форму:** відповіді падають у Google-таблицю тієї ж форми, як і раніше. Ніякого інтерфейсу Google на сайті не видно — форма повністю в стилі сайту.

## 🖥 Подивитися сайт локально

У терміналі, в папці проєкту:

```bash
python3 -m http.server 8000
```

Відкрий `http://localhost:8000`. Зупинити — `Ctrl+C`.

## 1️⃣ GitHub Pages — публікація

1. Увійди на **github.com** → **New repository**. Назва: `dianailiushchenko` (або будь-яка), тип **Public**, створи.
2. **Add file → Upload files**. Перетягни **усі файли + папку `images`** (папку `source-photos` можна пропустити). **Commit changes**.
3. **Settings → Pages** → **Source: Deploy from a branch** → Branch `main`, папка `/ (root)` → **Save**.
4. За 1–2 хв зверху зʼявиться *Your site is live at…*.

Файл `CNAME` GitHub підхопить сам.

## 3️⃣ Google Analytics (GA4) — лишилось зробити

1. **analytics.google.com** → **Admin** → **Create → Account** → далі **Property** («Сайт Діани»), часовий пояс — Україна.
2. Платформа **Web**, адреса `dianailiushchenko.com`.
3. Отримаєш **Measurement ID** виду `G-XXXXXXXXXX`.
4. **Надішли його мені** (або встав сам/сама): у `index.html` знайди блок `Google Analytics 4`, прибери навколо нього `<!--` та `-->`, і встав свій ID замість `G-XXXXXXXXXX` у **двох місцях**.

## 🔎 Варто перевірити у Google-формі

- **Приймання анонімних відповідей (важливо!):** Settings (шестерня) → **Responses** → вимкни «Limit to 1 response» і «Collect email addresses». Форма шле дані у фоні, тож якщо вона вимагає входу в Google — заявка мовчки не дійде, а відвідувач цього не побачить. Тому ці опції мають бути **вимкнені**.
- **Куди падають заявки:** вкладка **Responses → Link to Sheets** — створить таблицю з відповідями.
- **Тест:** відкрий сайт, заповни форму, натисни «Надіслати заявку» → маєш побачити «Дякую!», а в Google-таблиці зʼявитись новий рядок. (Поля прив'язані до форми через entry-коди — вони вже прописані в `script.js`; якщо колись переробиш поля у формі, коди треба оновити.)
